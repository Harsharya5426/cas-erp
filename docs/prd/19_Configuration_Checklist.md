# Configuration Checklist

## Institution
- [ ] Official logo and brand guide
- [ ] Exact website/ERP domain and DNS access
- [ ] Authorized administrators and approvers
- [ ] Department/program/subject catalogue
- [ ] Academic calendar, grading and attendance rules
- [ ] Fee schedules, refund and scholarship rules
- [ ] HR policies, payroll components and leave policies
- [ ] Certificate templates and authorized signatories
- [ ] Hostel/library/inventory/event policies

## Providers and integrations
- [ ] AWS account, approved region and billing owner
- [ ] Cashfree merchant account, API keys and webhook endpoints
- [ ] Email, SMS and WhatsApp Business provider accounts
- [ ] Google/Microsoft SSO tenant approvals
- [ ] Biometric/QR/RFID hardware and vendor documentation
- [ ] Accounting software and authorized data exchange
- [ ] AKTU interface documentation and written permissions

## Operations
- [ ] Data migration source access and data dictionary
- [ ] Data classification and retention schedule
- [ ] Privacy notices and consent/lawful-basis review
- [ ] Support contacts and escalation tree
- [ ] SLA, RTO and RPO
- [ ] Load/concurrency targets
- [ ] Pilot departments and user cohort
- [ ] Training plan and UAT signatories
